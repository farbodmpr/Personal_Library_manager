# Personal Library Manager

A command-line application built with Python to manage a personal book collection.

## Features

- Add new books to the library
- Display all stored books
- Search books by title or author
- Change reading status
- Delete books with confirmation
- Display library statistics
- Filter books by genre
- Sort books alphabetically (A–Z / Z–A)
- Validate user inputs

## Technologies Used

- Python
- Lists
- Functions
- Loops and Conditional Statements
- Match-Case
- Lambda Functions
- Generators
- String Methods

## Requirements

- Python 3.10 or higher

## How to Run

1. Clone this repository.
2. Open the project directory.
3. Run the following command:

```bash
python main.py
```

## Project Purpose

This project was developed to practice Python fundamentals and demonstrate the implementation of a menu-driven application using functions, data structures, and control flow.
